# Repubase

Sistema web de gestion de repuestos para talleres mecanicos PYMES.

## Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- Supabase Auth + Postgres + RLS

## MVP

- Registro e inicio de sesion con Supabase.
- Multi-taller con roles `administrador` y `mecanico`.
- Inventario de repuestos.
- Movimientos de stock por entrada, salida y ajuste.
- Alertas por stock mayor a 0 y mas de 90 dias sin movimiento.
- Dashboard basico con valor de inventario, cantidad de repuestos, stock total y ultimos movimientos.
